Proyek

Smash Point Padel Club

Situs reservasi lapangan padel. Proyek pribadi.
  • HTML
  • CSS
  • JavaScript
  • Node.js
  • Vercel
  • Git
Deskripsi
Situs untuk klub padel fiktif yang memungkinkan pengunjung memilih lapangan, tanggal, dan jam main, lalu langsung melihat ringkasan pesanan beserta total biayanya. Situs ini juga memuat informasi fasilitas, daftar harga, dan profil pelatih.
Fitur utama
  • Pemilihan lapangan dalam ruangan atau luar ruangan, dengan ketersediaan untuk 14 hari ke depan.
  • Slot bermain 90 menit dan pilihan pelatih, dengan total harga yang diperbarui otomatis.
  • Tiga paket harga: pemesanan tunggal, paket bulanan, dan paket korporat.
  • Tampilan menyesuaikan layar ponsel hingga komputer.
Peran saya
Mengerjakan seluruh proyek sendiri: merancang tampilan, menulis antarmuka dengan HTML, CSS, dan JavaScript, serta membuat berkas sisi server untuk memeriksa ketersediaan lapangan dan mencatat pemesanan. Kode disimpan di GitHub dengan Git dan diterbitkan lewat Vercel.
Yang saya pelajari
Memisahkan tampilan dari logika server, menangani data tanggal dan jam, serta alur menerbitkan situs dari repositori GitHub ke Vercel.

Whimsical To Do List

Aplikasi daftar tugas. Proyek pribadi.
  • HTML
  • CSS
  • JavaScript
  • Git
  • GitHub Pages
Deskripsi
Aplikasi daftar tugas sederhana dengan tampilan yang ceria. Pengguna dapat menambahkan tugas, menyaring tugas yang jatuh pada hari ini, mengatur ulang daftar, atau menghapus semua tugas sekaligus.
Fitur utama
  • Menambah tugas baru dengan satu formulir singkat.
  • Filter “Today Only” untuk memfokuskan pekerjaan hari ini.
  • Tombol atur ulang dan hapus semua tugas.
Peran saya
Membangun aplikasi sendiri dari awal hingga tayang: menyusun struktur dengan HTML, mengatur gaya dengan CSS, dan menulis logika interaksi dengan JavaScript. Kodenya dikelola dengan Git dan diterbitkan melalui GitHub Pages.
Yang saya pelajari
Memanipulasi elemen halaman dengan JavaScript, menangani peristiwa klik dan input, serta menyusun tampilan yang tetap nyaman dipakai.
